# Geotab 일련번호 매칭 / 실제 위치 표시

## 화면 및 권한

- 테넌트 관리자: **설정 > 지오펜스 > Geotab 단말 · 차량번호 매칭**.
- 운영 super_admin: 회사 scope를 선택한 단말 장착 화면에도 동일 매칭 패널 제공.
- 수집 일련번호, provider deviceId(`b1` 등), 데이터베이스, 단말 보고 VIN, provider 번호판 유무, 현재 Pangea 차량번호를 구분 표시.
- 차량번호/VIN 검색은 선택한 테넌트의 활성 차량만 반환하며 최대 100개, 초과 시 검색 안내.
- 명시적 매칭/해제는 관리자만 가능. 변경 충돌(revision)·다른 차량 중복 매칭은 오류 표시하며 성공으로 표시하지 않음.
- 최초 매칭에 한해 장착 시점을 지정 가능. 과거 차량 이동 이력을 임의 재할당하지 않도록 이후 변경은 현재부터 적용.
- installer의 화면 권한은 기존대로 유지. 배정된 작업에서 일련번호를 입력하면 수집 여부를 확인하며, 완료 결과에 매칭 완료/수집 대기/충돌이 표시됨.

## 지도

- 도난 의심/사고 확인 카드 및 매칭된 단말 패널에서 최근 위치 팝업.
- 최근 위치 50개 좌표를 시간순 경로와 최근 마커로 표시; 기록 시각은 실제 수집 시각.
- Kakao 키가 있으면 기존 SDK, 없으면 가시 영역만 요청하는 OSM 배경 지도 사용.
- OSM 공급자에는 단말번호/VIN/전체 경로를 보내지 않으며, 브라우저가 배경 타일을 캐시한다. 화면에 attribution 표시. 상용 규모 확대 시 공급자 정책·계약을 검토할 것.
- 배경 타일 실패 시 오류 안내와 경로/좌표 유지. 확대·축소·드래그·경로 맞춤 지원.

## 기준값

테넌트 설정: 체류 30분, fallback 반경 100m, 충돌 AI 신뢰도 50, 알림 신선도 15분, 위치 수집 공백 10분. 외부 ΔV는 m/s 단위가 있는 신호에만 적용하며 실제 Geotab 가속도 m/s²와 혼용하지 않는다. AI 신뢰도는 피해 심각도가 아니다.

## 검증

- 실제 계정/Collector/로컬 Mongo를 연결한 API로 단말 1대, 실제 최근 경로 50개, 지도 타일 및 최근 마커를 브라우저에서 확인.
- 샘플 차량 표기는 `EDA-샘플(실제번호아님)`이며 실제 번호판을 추정하지 않음.
- `e2e/geotab-telemetry.spec.ts`: 사고 확인→접수, 지도 경로, 일련번호→차량번호 매칭, 매칭 충돌 3개 테스트.
- 빌드 통과. 모의 API 전체 UI 89개 중 78통과/11실패. 실패 11개는 변경 전 `2feeda7`의 동일 조건에서 재현(결제/면허/권한 시나리오)했다. 고객매뉴얼 실연동 smoke 2개는 별도의 데모 데이터가 필요해 이 실행에서 제외했다.
- API/SDK 응답 EDA와 사고·고장 분류 및 자세한 실행 결과는 BE 저장소 `docs/geotab_eda_20260929.md` 참조.
